# Deterministic converse with four inputs

## Setting and theorem

The input is $`n`$ independent copies of

```math
\rho_{\mathbf u}(r)=\frac{I+r\,\mathbf u\cdot\boldsymbol\sigma}{2},
\qquad
\psi_{\mathbf u}=\frac{I+\mathbf u\cdot\boldsymbol\sigma}{2},
\qquad \mathbf u\in S^2,\quad 0\lt r\lt 1.
\tag{D1}
```

The unknown direction $`\mathbf u`$ specifies the target pure state. An unprocessed input has fidelity $`F_0(r)=(1+r)/2`$. A deterministic protocol is a completely positive, trace-preserving map $`\mathcal E`$ from the $`n`$ inputs to one output qubit. It may depend on $`r`$, but not on $`\mathbf u`$. Its Haar-average fidelity is

```math
F_{\mathcal E}(r)=\int_{S^2}
\mathrm{tr}\!\left[
\psi_{\mathbf u}\mathcal E(\rho_{\mathbf u}(r)^{\otimes n})
\right]d\mu(\mathbf u),
\tag{D2}
```

with normalized uniform measure $`\mu`$. An output is returned on every run; there is no postselection in (D2).

As in the heralded setting, the free class is specified by a Choi operator in the positive cone generated by pure stabilizer projectors. For channels this is the completely stabilizer-preserving class. It includes Clifford gates, stabilizer ancillas, Pauli measurements, classical randomness and feedforward, and discarding, with arbitrary adaptive compositions. This inclusion follows by applying the protocol to halves of Bell pairs: the normalized Choi operator is then a stabilizer mixture.

**Theorem D.** For every such channel with $`n\le4`$ input copies and every $`0\lt r\lt 1`$,

```math
F_{\mathcal E}(r)\le\frac{1+r}{2}.
\tag{D3}
```

Returning one input attains equality. In particular, deterministic processing of at most four copies cannot strictly improve fidelity for every direction. An ordinary five-copy stabilizer protocol does improve every direction for

```math
0\lt r\lt r_*:=\sqrt{-7+2\sqrt{13}}.
\tag{D4}
```

Thus the exact deterministic minimum is five throughout this interval, whereas the exact heralded minimum there is four. These are copy thresholds for the existence of universal gain, not a classification at every polarization.

The qubit two-copy no-go was proved by He et al. [1, Theorem 2]. The four-copy deterministic converse below uses trace preservation in an essential way and does not assert a four-copy heralded no-go.

## Choi convention

Label the four input references by $`1,2,3,4`$ and the output by $`o`$. The unnormalized Choi operator is

```math
J=(\mathrm{id}\otimes\mathcal E)
\bigl(|\Omega_4\rangle\langle\Omega_4|\bigr),
\qquad
|\Omega_4\rangle=\sum_{x\in\{0,1\}^4}|x\rangle|x\rangle.
\tag{D5}
```

For input $`X`$ and output observable $`Y`$,

```math
\mathrm{tr}[Y\mathcal E(X)]
=\mathrm{tr}[J(X^T\otimes Y)].
\tag{D6}
```

Trace preservation gives

```math
\mathrm{tr}_oJ=I_{1\cdots4},
\qquad \mathrm{tr}J=16,
\qquad j:=J/16,
\qquad \mathrm{tr}_oj=I_{1\cdots4}/16.
\tag{D7}
```

The normalized state $`j`$ is a five-qubit stabilizer mixture. We use $`\langle O\rangle=\mathrm{tr}(jO)`$, with identity factors implicit, and

```math
\sigma_a^T=t_a\sigma_a,
\qquad t_x=t_z=1,\quad t_y=-1.
\tag{D8}
```

## A five-qubit stabilizer inequality

Define

```math
\begin{aligned}
\mathsf B_4
&=\sum_{i=1}^4\sum_{a=x,y,z}
t_a\sigma_a^{(i)}\sigma_a^{(o)},\\
K_a&=\sigma_a^{(1)}\sigma_a^{(2)}
\sigma_a^{(3)}\sigma_a^{(4)},\\
\mathsf D&=K_x+K_y+K_z,
\qquad B=\langle\mathsf B_4\rangle,
\quad D=\langle\mathsf D\rangle.
\end{aligned}
\tag{D9}
```

**Lemma D1.** For every five-qubit stabilizer mixture,

```math
B\le3+D.
\tag{D10}
```

This is an expectation inequality on the stabilizer set; it is not asserted as an operator inequality on all five-qubit states.

**Proof.** The four-input Pauli strings $`K_x,K_y,K_z`$ commute and satisfy $`K_xK_y=K_z`$. If the first two have joint eigenvalues $`x,y\in\{\pm1\}`$, their sum with the third has eigenvalue $`x+y+xy\in\{3,-1\}`$. Hence

```math
\mathsf D\ge-I,
\qquad D\ge-1
\tag{D11}
```

for every quantum state. This proves (D10) whenever $`B\le2`$.

It remains to consider pure stabilizer states with $`B\gt 2`$; convexity will then give the general result. In a pure stabilizer state, every Hermitian Pauli expectation is $`0`$ or $`\pm1`$, and a nonzero expectation fixes a Pauli eigenvalue.

**An isolated Bell pair.** Suppose that for some input $`i`$, at least two of
$`X_iX_o`$, $`Y_iY_o`$, and $`Z_iZ_o`$ have nonzero expectation. Those two independent commuting Paulis fix a Bell state on qubits $`i,o`$. The global pure state factors into this Bell pair and the remaining three inputs. All other input-output pair correlations vanish because the output marginal of a Bell state is maximally mixed. The Bell pair contributes at most three to $`B`$. Each $`\langle K_a\rangle`$ also vanishes because it contains a nonidentity Pauli on the isolated Bell-pair input. Thus $`B\le3`$ and $`D=0`$, proving (D10) in this case.

**No isolated Bell pair.** Each input then has at most one nonzero correlation among the three pair Paulis above. Furthermore, any two nonzero pair correlations on distinct inputs must use the same Pauli axis. Indeed, for $`i\ne k`$ and $`a\ne b`$, the operators $`\sigma_a^{(i)}\sigma_a^{(o)}`$ and $`\sigma_b^{(k)}\sigma_b^{(o)}`$ anticommute. They cannot both have expectation $`\pm1`$ in the same state. All nonzero correlations therefore share a common axis $`a`$.

Put

```math
P_i=\sigma_a^{(i)}\sigma_a^{(o)},
\qquad c_i=t_a\langle P_i\rangle\in\{-1,0,1\}.
\tag{D12}
```

Then $`B=\sum_i c_i`$ is an integer at most four. After the already settled case $`B\le2`$, only the following two cases remain.

If $`B=3`$, exactly three of the $`c_i`$ equal $`+1`$, and the remaining one is zero. Let the absent index be $`\ell`$. Each of the three present pair Paulis $`P_i`$ has eigenvalue $`t_a`$. Their product $`Q=\prod_{i\ne\ell}P_i`$ has eigenvalue $`t_a^3=t_a`$, and $`K_a=QP_\ell`$. Therefore

```math
\langle K_a\rangle=t_a\langle P_\ell\rangle=0.
\tag{D13}
```

For either other axis $`b\ne a`$, $`K_b`$ anticommutes with any of the three present pair Paulis $`P_i`$, so $`\langle K_b\rangle=0`$. It follows that $`D=0`$, and (D10) is saturated.

If $`B=4`$, all four $`c_i`$ equal $`+1`$. Now

```math
K_a=\prod_{i=1}^4P_i,
\qquad \langle K_a\rangle=t_a^4=1.
\tag{D14}
```

The two perpendicular four-input strings again have zero expectation by anticommutation. Hence $`D=1`$, and (D10) is again saturated. The factor $`t_y=-1`$ causes no exception: it appears four times in (D14).

These cases exhaust pure stabilizer states. Taking positive convex combinations proves the lemma. $`\square`$

For a channel, (D7) gives $`D=0`$, since each $`K_a`$ is a nonidentity input-only Pauli. Lemma D1 therefore implies

```math
B\le3.
\tag{D15}
```

This use of the maximally mixed input Choi marginal is the step that distinguishes deterministic processing from heralded processing.

## Exact four-copy Haar coefficients

For completeness, define the input-only operators

```math
\mathsf A_4=\sum_{1\le i\lt k\le4}\sum_{a=x,y,z}
\sigma_a^{(i)}\sigma_a^{(k)}
\tag{D16}
```

and

```math
\begin{aligned}
\mathsf T_4=\sum_{a,b=x,y,z}\bigl(&
\sigma_a^{(1)}\sigma_a^{(2)}\sigma_b^{(3)}\sigma_b^{(4)}\\
&+\sigma_a^{(1)}\sigma_b^{(2)}\sigma_a^{(3)}\sigma_b^{(4)}\\
&+\sigma_a^{(1)}\sigma_b^{(2)}\sigma_b^{(3)}\sigma_a^{(4)}\bigr).
\end{aligned}
\tag{D17}
```

The coefficient involving three inputs and the output is

```math
\mathsf C_4=
\sum_{\substack{T\subseteq\{1,2,3,4\}\\ |T|=3}}
\ \sum_{k\in T}\ \sum_{a,b=x,y,z}
t_b\sigma_a^{(i)}\sigma_a^{(\ell)}
\sigma_b^{(k)}\sigma_b^{(o)},
\qquad \{i,\ell\}=T\setminus\{k\}.
\tag{D18}
```

There are four input triples and three ways to pair the output index with an input index in each triple. The sums in (D17) and (D18) retain all three fourth-moment pairings when $`a=b`$, as required.

Using

```math
\int u_a u_b\,d\mu=\frac{\delta_{ab}}3,
\qquad
\int u_a u_b u_c u_d\,d\mu
=\frac{\delta_{ab}\delta_{cd}+\delta_{ac}\delta_{bd}
+\delta_{ad}\delta_{bc}}{15},
\tag{D19}
```

and vanishing odd moments, direct expansion yields the operator identity

```math
\begin{aligned}
Q_4(r)&:=\int
\bigl(\rho_{\mathbf u}(r)^T\bigr)^{\otimes4}
\otimes\psi_{\mathbf u}\,d\mu(\mathbf u)\\
&=\frac1{32}\left[
I+\frac{r^2}{3}\mathsf A_4+\frac{r^4}{15}\mathsf T_4
+\frac r3\mathsf B_4+\frac{r^3}{15}\mathsf C_4
\right].
\end{aligned}
\tag{D20}
```

The transpose signs on inputs paired together cancel. The input paired with the output supplies the remaining $`t_b`$ in (D18). No term of order $`r^4`$ can couple to the output Bloch vector: it would contain an odd fifth sphere moment.

All terms in $`\mathsf A_4`$ and $`\mathsf T_4`$ are nonidentity input-only Paulis. Hence (D7) gives their zero expectation in $`j`$. Writing $`C=\langle\mathsf C_4\rangle`$, equations (D6), (D7), and (D20) give the complete deterministic fidelity polynomial

```math
F_{\mathcal E}(r)=\mathrm{tr}[JQ_4(r)]
=\frac12+\frac B6r+\frac C{30}r^3.
\tag{D21}
```

## Endpoint interpolation and equality

Subtracting the input fidelity from (D21),

```math
F_{\mathcal E}(r)-\frac{1+r}{2}
=\frac r2 q(r^2),
\qquad
q(s)=\left(\frac B3-1\right)+\frac C{15}s.
\tag{D22}
```

The correlation bound (D15) gives $`q(0)\le0`$. At $`r=1`$, complete positivity and trace preservation imply that $`\mathcal E(\psi_{\mathbf u}^{\otimes4})`$ is a density operator for each direction. Its fidelity with $`\psi_{\mathbf u}`$ is at most one. Thus

```math
q(1)=2\bigl[F_{\mathcal E}(1)-1\bigr]\le0.
\tag{D23}
```

Equivalently, this endpoint follows by taking the Choi expectation of the positive operator
$`\int(\psi_{\mathbf u}^T)^{\otimes4}\otimes(I-\psi_{\mathbf u})\,d\mu`$.
For a channel success is one even at the pure endpoint; no conditional normalization is used.

Affineness now gives $`q(s)=(1-s)q(0)+sq(1)\le0`$ for $`0\le s\le1`$, proving (D3) for four copies. The channel is held fixed during this interpolation. Since the result holds for every channel, allowing the actual protocol to depend on the input polarization does not change the bound.

Any channel using fewer than four inputs can be padded to four inputs by discarding unused copies. This preserves the Choi stabilizer condition and its fidelity on identical inputs. The bound therefore applies to every $`n\le4`$. Returning one input attains equality for every direction, proving that the optimal deterministic Haar fidelity for these budgets is exactly the raw fidelity. In particular, strict fidelity improvement at every direction is impossible, since it would strictly increase the Haar average.

## Attainability and the five-copy threshold

The [five-copy construction](constructions.md) reserves one untouched input as a fallback for the four-copy heralded instrument. It is an ordinary stabilizer channel and strictly improves every direction for $`0\lt r\lt r_*`$, with $`r_*`$ given in (D4). Its channel definition on arbitrary inputs, resource accounting, fidelity formula, and attribution are given on the construction page.

Together with Theorem D, this proves that the minimum deterministic copy count is exactly five throughout the displayed interval. The converse covers the full completely stabilizer-preserving class, while attainment uses ordinary stabilizer processing, so the threshold is the same in both classes. Combined with the [heralded converse](heralded-converse.md), the resulting distinction is four copies with heralding and five when an output must always be returned. This is an onset theorem: it does not supply an optimal fidelity curve or a complete classification at larger polarization.
